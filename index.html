Bachelor in Applied Mathematics · Year 2

Mathematical Modeling

How simple rules produce outbreaks, rhythms, flocks and patterns. Each model is derived in a theory session, explored with interactive figures, and then built in Python in the lab.

Start with Module 1 Browse the course map

Academic year 2026–27 · David Gómez-Ullate and Daniel Precioso · IE University

How the course works

  • Theory first

    Start from a real phenomenon, write the model, and analyse it: fixed points, stability, bifurcations.

  • Interactive figures

    Move a slider, click a starting point, sweep a parameter, and watch the mathematics respond, right inside the notes.

  • Then the lab

    Implement the same model in Python with NumPy and SciPy, reproduce the figures, and go beyond them.

  • Projects

    Assignments, explorables presentations and a final group project turn the examples into your own investigations.

Course at a glance

  • Format: 6 modules organized into 32 sessions
  • Tools: Python, NumPy, SciPy, matplotlib, Streamlit, NetworkX, plus interactive figures that run in the browser
  • Main goal: learn mathematical modeling through analysis, simulation, and interpretation

Learning Approach

  • Start from a mathematical model and identify its main variables, parameters, and assumptions.
  • Move from qualitative reasoning to numerical simulation and visual interpretation.
  • Compare related models across sessions so each new topic extends a familiar workflow.
  • Use the assignments to turn lecture examples into independent investigations.

What you will build

Across the course you will implement and experiment with:

  • Low-dimensional dynamical systems (spruce budworm, SIR/SIS, CDIMA, Van der Pol, FitzHugh-Nagumo)
  • Coupled oscillator simulations (Kuramoto synchronization and the Millennium Bridge)
  • Collective motion models (Vicsek, Couzin, social force, predator response)
  • Random walks and statistical modelling (diffusion, heavy tails, financial returns)
  • Network analysis and spreading simulations (metrics, graph models, SIS/SIR)
  • Reaction-diffusion solvers and Turing analysis (Gierer-Meinhardt, Gray-Scott)
  • Discrete and agent-based explorables (cellular automata, traffic flow, congestion)

How to Use the Material

  • Read each module overview first so the mathematical question and modeling goal are clear.
  • Use the lecture slides as a compact guide to the main ideas and calculations.
  • Work through the case studies in order before starting the assignment.
  • Return to earlier modules when a later topic reuses the same analytical or numerical pattern.

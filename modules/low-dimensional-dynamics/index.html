Module 1: Low-Dimensional Dynamics

Part I of the syllabus, Sessions 1 to 9

This module covers models with one or two state variables described by ordinary differential equations. You start with a single equation for an insect population and learn to find equilibria, decide their stability and follow them as parameters change. You then apply the same tools to epidemics, fit a model to data, and move to the plane, where oscillations, limit cycles, Hopf bifurcations and excitable systems appear (Strogatz 2024). Lectures and laboratories alternate: each lecture is followed by a session in which you implement the model in Python. Reusable code is in amlab/odes_1d/, amlab/odes_2d/ and amlab/epidemics/.

Learning Goals

  • Formulate a model as an ODE, and remove units to reduce the number of parameters.
  • Find equilibria and decide their stability from the linearization.
  • Recognize saddle-node and Hopf bifurcations, bistability and hysteresis.
  • Integrate ODEs with scipy.integrate.solve_ivp, and validate the result against known solutions.
  • Build interactive tools (Streamlit apps, Matplotlib animations and clickable parameter maps).
  • Use SIR and SIS models to compute reproduction numbers, herd immunity thresholds and final sizes.
  • Fit a model to incidence data and explain why the peak of an epidemic is hard to predict.
  • Read a phase plane: nullclines, fixed points, limit cycles, excitability and relaxation oscillations.

References

Strogatz, Steven H. 2024. Nonlinear Dynamics and Chaos: With Applications to Physics, Biology, Chemistry, and Engineering. Chapman; Hall/CRC.

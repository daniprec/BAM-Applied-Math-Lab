Animation in 2D

Module 4: Space and Pattern Formation

Once the 2D Euler loop on Gierer-Meinhardt Solver in 2D passes the time-step check, you can look at the field. Plot one static snapshot first. Animate only after the snapshot looks right, as in Animation in 1D.

Plot a Snapshot

imshow draws the matrix uv[1]. Rows are \(x\) and columns are \(y\), so the horizontal axis of the image is \(y\).

import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(7, 4))
im = ax.imshow(
    uv[1],
    interpolation="bilinear",
    origin="lower",
    extent=[0, length_y, 0, length_x],
)
ax.set_xlabel("y")
ax.set_ylabel("x")
plt.colorbar(im, ax=ax, label="v(x, y)")
plt.show()

## Solution

`global` is needed because the callback reassigns `uv`. Inside a wrapping function, use `nonlocal` instead.

```python
def update_frame(_):
    global uv
    for _ in range(steps_per_frame):
        uv = uv + dt * gierer_meinhardt_pde_2d(0, uv, d=30, dx=dx)
        uv = apply_boundary_conditions(uv, bc="neumann")
    im.set_array(uv[1])
    return (im,)
```

Solution 
def update_frame(_):
    global uv
    for _ in range(steps_per_frame):
        uv = uv + dt * gierer_meinhardt_pde(0, uv, d=30, dx=dx)
        uv = apply_boundary_conditions_1d(uv, bc="neumann")
    plot_v.set_ydata(uv[1])
    return (plot_v,)

global is needed because the callback reassigns uv. If you wrap everything inside a function, as amlab.pdes_1d.gierer_meinhardt_1d.run_simulation does, use nonlocal instead.

Save Frames for the Assignment

The assignment asks for one frame every 500 steps. A loop that stores snapshots is simpler than recording the live animation.

frames = []
for step in range(50000):
    uv = uv + dt * gierer_meinhardt_pde(0, uv, d=30, dx=dx)
    uv = apply_boundary_conditions_1d(uv, bc="neumann")
    if step % 500 == 0:
        frames.append(uv[1].copy())

Exercise

Predict first, then run the animation to check.

  • Run Case A (\(d = 30\)) and Case B (\(d = 20\)). Which one keeps its peaks?
  • In Case A, count the half-wavelengths at \(t = 100\) and at \(t = 500\). Does the count match the leading mode \(n = 5\) from Unstable Modes in 1D, or does mode \(6\) win for some seeds?
  • Change the seed. Do the peak positions move? Does the spacing change?
Solution

Case A keeps its peaks and Case B returns to the flat state, with \(\max v - \min v\) at rounding level by \(t = 500\). With \(dx = 1\), \(dt = 0.01\) and seeds \(0\) to \(9\), every Case A run shows five half-wavelengths at \(t = 500\), the leading mode \(n = 5\). At \(t = 100\) the amplitude is still small (about \(0.04\)) and a few seeds still show six, because modes \(5\) and \(6\) grow at almost the same rate. Changing the seed moves the peaks, and for this domain the final profile is one of two mirror images, but the spacing stays the same.

import numpy as np
from amlab.turing import simulate_gm_1d


def count_half_waves(v):
    slope = np.sign(np.diff(v[1:-1]))
    slope = slope[slope != 0]
    return 1 + np.sum(slope[1:] != slope[:-1])


for seed in range(10):
    counts = [
        count_half_waves(simulate_gm_1d(d=30.0, t_end=t, bc="neumann", seed=seed)[1][1])
        for t in (100, 500)
    ]
    print(seed, counts)

Turing Numerics

Module 4: Space and Pattern Formation

This is the prediction step of the laboratory. You turn the theory of Turing Conditions and Dispersion Relation into three small functions: equilibrium, Jacobian, and Turing test (Turing 1952; murray2003mathematical?). The fourth, the mode scan, follows on Unstable Modes in 1D. You will reuse all four in 2D and in the assignment.

The workflow is always the same:

  • Find the homogeneous equilibrium.
  • Compute the Jacobian at that equilibrium.
  • Compute the Laplacian eigenvalues from the domain and the boundary conditions.
  • Build the mode matrix \(A_n = \gamma J - k_n^2 D\) for each mode.
  • Compute the eigenvalues of each \(2 \times 2\) matrix and keep the modes whose largest real part is positive.

Compute the Equilibrium

The steady state from Linearization is one line of code each.

def gierer_meinhardt_equilibrium(a=0.40, b=1.00):
    u_star = (a + 1) / b
    v_star = u_star**2
    return u_star, v_star

Solution 
def gierer_meinhardt_jacobian(a=0.40, b=1.00):
    u_star, v_star = gierer_meinhardt_equilibrium(a, b)
    fu = -b + 2 * u_star / v_star
    fv = -(u_star**2) / (v_star**2)
    gu = 2 * u_star
    gv = -1.0
    return fu, fv, gu, gv

Simplified, this is \(f_u = b(1-a)/(1+a)\), \(f_v = -b^2/(1+a)^2\), \(g_u = 2(1+a)/b\), \(g_v = -1\). You can also write the entries directly in \(a\) and \(b\):

def gierer_meinhardt_jacobian(a=0.40, b=1.00):
    fu = 2 * b / (a + 1) - b
    fv = -((b / (a + 1)) ** 2)
    gu = 2 * (a + 1) / b
    gv = -1.0
    return fu, fv, gu, gv

Solution 
def is_turing_instability(a, b, d):
    fu, fv, gu, gv = gierer_meinhardt_jacobian(a, b)
    det = fu * gv - fv * gu
    cond1 = (fu + gv) < 0
    cond2 = det > 0
    cond3 = (d * fu + gv) > 0
    cond4 = (d * fu + gv) ** 2 > 4 * d * det
    return cond1 & cond2 & cond3 & cond4

The course package writes the last two conditions as the single inequality \(d f_u + g_v > 2\sqrt{d \det J}\), which is equivalent.

If your implementation is vectorized, it works with scalars and with arrays. Validate it carefully: you reuse it in 2D and in the assignment.

Vicsek Lab: Initialization

Module 2: Synchronization and Collective Behaviour

In this lab you implement the Vicsek model (Vicsek et al. 1995), validate it, and animate it. The rules are in The Vicsek Model.

ImportantCore activity

The core of this lab is five pages: this one, Update Rule, Order Parameter, Validation and Animation. Vectorized Update, Interactive Animation and Predator Avoidance are optional extensions. Practice: Collective Motion closes the session.

Why not solve_ivp?

In Module 1 you used ODE solvers like scipy.integrate.solve_ivp() for continuous-time systems. The Vicsek model is a discrete-time, agent-based model. At each step all particles update their heading and position from their neighbours and some noise. There is no differential equation to integrate, so you implement it with a loop over time steps.

Prediction

NoteExercise

Before you code, write down your expectations.

  • With noise \(\eta = 0\) and a large interaction radius, what is the order parameter after many steps?
  • With \(\eta = 2\pi\), what is it for \(N = 100\)?
  • At fixed noise, does increasing the density help or hurt alignment?
TipSolution

With no noise and every particle seeing every other, all headings converge to one direction and \(v_a \to 1\). With \(\eta = 2\pi\) every heading is random at every step, so \(v_a\) is of order \(1/\sqrt{N} = 0.1\). Higher density means more neighbours inside the radius, which averages out the noise and helps alignment (Vicsek et al. 1995).

## Solution

```python
def initialize_particles(num_boids, box_size):
    theta = np.random.uniform(0, 2 * np.pi, num_boids)
    xy = np.random.uniform(0, box_size, (2, num_boids))
    return xy, theta
```

Try out your function now. @vicsek1995novel used between $N = 40$ and $N = 10000$ particles and box sizes between $L = 3$ and $L = 50$. The more particles you have, the slower the simulation will be, so start with a small number like $N=100$ and a box size of $L=10$.


@fig-vicsek shows what you are building: after a few steps, nearby particles already point in similar directions.

```{python}
#| label: fig-vicsek
#| fig-cap: 'Vicsek model after 20 steps: $N = 100$ particles in a box of side $L = 10$, noise $\eta = 0.5$. Arrows show headings and grey dots the recent trajectory.'
#| fig-width: 6
#| fig-height: 6
#| echo: false

import numpy as np
import matplotlib.pyplot as plt
from amlab.collective_motion.vicsek import initialize_particles, vicsek_equations

np.random.seed(0)  # the amlab functions use NumPy's global generator
num_boids = 100
box_size = 10
xy, theta = initialize_particles(num_boids, box_size=box_size)

# We will store the last 20 positions for each particle to plot tails
xy_tail = np.zeros((2, num_boids, 20))

# Evolve for a few steps to show a more interesting configuration
for _ in range(20):
    xy, theta = vicsek_equations(
        xy,
        theta,
        noise=0.5,
        box_size=box_size,
    )
    xy_tail = np.roll(xy_tail, shift=-1, axis=2)  # shift tail positions
    xy_tail[:, :, -1] = xy  # add current position to tail

fig, ax = plt.subplots(figsize=(6, 6))
ax.set_xlim(0, box_size)
ax.set_ylim(0, box_size)
ax.set_aspect("equal")
# Plot tails as a single line (flattened)
ax.plot(
    xy_tail[0].flatten(),
    xy_tail[1].flatten(),
    color="grey",
    linestyle="",
    marker=".",  # using dots avoids connecting lines between tails of different particles
    markersize=2,
)
# Plot headings as quivers
ax.quiver(
    xy[0],
    xy[1],
    np.cos(theta),
    np.sin(theta),
    angles="xy",
    scale_units="xy",
    scale=5,
)
plt.show()
plt.close()
```

Implementation: define the ODE

Choose between the pairwise form of the Kuramoto model and the mean-field form. They are mathematically identical (The Order Parameter). The mean field approximation is often more efficient for large populations, as it avoids computing pairwise interactions.

The right-hand side only uses \(\sin\) and \(e^{i\theta}\), which are \(2\pi\)-periodic, so the dynamics do not need the phases to stay in \([0, 2\pi)\). Wrapping with np.mod(theta, 2 * np.pi) is still useful before plotting.

The function below uses the mean-field form, which is cheaper than computing pairwise interactions. It computes the order parameter at each call and uses it to calculate the derivatives.

def kuramoto_ode(t, theta, omega, coupling_strength=1.0):
    # Wrapping is optional: sin and exp are 2 pi-periodic
    theta = np.mod(theta, 2 * np.pi)
    order_param = np.mean(np.exp(1j * theta))
    r = np.abs(order_param)
    phi = np.angle(order_param)
    dtheta_dt = omega + coupling_strength * r * np.sin(phi - theta)
    return dtheta_dt

## Validation: two known regimes

You know the answer in two regimes. For strong coupling, $K = 10 \gg K_c$, the oscillators should cluster. For weak coupling, $K = 0.1 \ll K_c$, they should stay spread around the circle. @fig-kuramoto-k-high and @fig-kuramoto-k-low show sample outputs for $N = 100$ and $\sigma = 1$ at $t = 10$.

```{python}
#| label: fig-kuramoto-k-high
#| fig-cap: 'Visualization of oscillators after running the Kuramoto ODE for K=10. The clustering of the blue dots indicates synchronization.'
#| fig-width: 6
#| fig-height: 6
#| echo: false
import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import solve_ivp
from amlab.odes_coupled.kuramoto import initialize_oscillators, kuramoto_ode_meanfield

# Parameters
coupling_strength = 10.0
num_oscillators = 100
sigma = 1.0
t_span = (0, 10)

# Initialize oscillators
theta, omega = initialize_oscillators(
    num_oscillators,
    distribution="normal",
    scale_omega=sigma,
    seed=1,
    )

# Run the simulation
sol = solve_ivp(
    kuramoto_ode_meanfield,
    t_span,
    theta,
    args=(omega, coupling_strength)
    )
theta_end = sol.y[:, -1]

x = np.cos(theta_end)
y = np.sin(theta_end)
fig, ax = plt.subplots(figsize=(6, 6))
ax.set_title("Kuramoto Model - K = 10")
ax.set_xlabel("Cos(theta)")
ax.set_ylabel("Sin(theta)")
ax.set_xlim(-1.1, 1.1)
ax.set_ylim(-1.1, 1.1)
ax.set_aspect("equal")
ax.grid(True)
# Draw unit circle (optional, but it helps to visualize the boundary)
circle = plt.Circle((0, 0), 1, color="lightgray", fill=False)
ax.add_artist(circle)
ax.scatter(x, y, s=50, color="blue", alpha=0.5)
plt.show()
plt.close()
```

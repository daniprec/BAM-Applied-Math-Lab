Loading Prices and Computing Returns

Module 3: Modelling with Randomness

In this laboratory you test the random walk model of Returns and Efficient Markets on a daily price series. The lab has five pages: this one (returns and autocorrelation), Normality Tests, Calibrated KS Test, Tail Exponent and Scaling of Returns in Data.

Reading
  • Recommended: (cont2001empirical?), Sections 2 and 5.
Which data you are using

amlab.finance.load_prices() reads the frozen file data/finance/prices.csv (columns date,close) when it is present in the repository. If the file is missing, it prints a warning and returns a synthetic GARCH(1,1) series with Student-t innovations and a fixed seed (bollerslev1986generalized?). The synthetic series is not market data. Check the printed message below before you interpret any number. The file format is described in data/finance/README.md.

Prediction

Exercise

Before you run any code, write down your answers:

  • What order of magnitude do you expect for the standard deviation of daily log returns of a stock index: 0.01 %, 1 % or 10 %?
  • If the market is weak-form efficient, what should the autocorrelation of \(r_t\) at lag 1 be?
  • Should the autocorrelation of \(|r_t|\) at lag 1 be zero too?
Solution
  • About 1 %. A typical stock index moves by roughly one percent on an ordinary day.
  • Close to zero. A clear linear correlation would let you forecast tomorrow’s return from today’s.
  • No. Efficiency says nothing about the size of the moves. Large moves tend to follow large moves (volatility clustering), so the autocorrelation of \(|r_t|\) is positive (cont2001empirical?). You check both answers below.

Exercise

Write a function that returns the log returns \(r_t = \ln(P_t / P_{t-1})\) of a price array.

def log_returns(prices):
    """Log returns of a 1D array of positive prices."""
    # TODO: take the logarithm of the prices and difference it
    return ...
Solution 
def log_returns(prices):
    """Log returns of a 1D array of positive prices."""
    return np.diff(np.log(np.asarray(prices, dtype=float)))


prices = df["close"].to_numpy()
dates = df["date"].to_numpy()
r = log_returns(prices)
print(f"{r.size} returns, mean {r.mean():.2e}, std {r.std():.4f}")
5000 returns, mean -1.09e-04, std 0.0091

The same function is available as amlab.finance.log_returns.

Validation

Two checks catch most mistakes:

  • There is one return fewer than there are prices.
  • Log returns add up: \(\sum_t r_t = \ln(P_T / P_0)\).
assert r.size == prices.size - 1
assert np.isclose(r.sum(), np.log(prices[-1] / prices[0]))
print("checks passed")
checks passed

Experiment: autocorrelation of returns and absolute returns

Under the null hypothesis of i.i.d. returns, sample autocorrelations are approximately normal with standard deviation \(1/\sqrt{n}\), so values outside \(\pm 2/\sqrt{n}\) are unusual.

Exercise

Complete the function below. Then compute the sample autocorrelation of \(r_t\) and of \(|r_t|\) for lags 1 to 50 and plot both with the \(\pm 2/\sqrt{n}\) band.

def autocorrelation(x, max_lag):
    """Sample autocorrelation at lags 0..max_lag."""
    x = x - x.mean()
    # TODO: for each lag k, compute sum(x[:-k] * x[k:]) / sum(x * x)
    return ...
Solution

Lag 0 needs care, because x[:-0] is empty. Slice with x[: x.size - k] instead.

def autocorrelation(x, max_lag):
    """Sample autocorrelation at lags 0..max_lag."""
    x = x - x.mean()
    return np.array([np.sum(x[: x.size - k] * x[k:]) / np.sum(x * x) for k in range(max_lag + 1)])

The same function is available as amlab.finance.autocorrelation, which the plot below uses.

from amlab.finance import autocorrelation

lags = np.arange(1, 51)
acf_r = autocorrelation(r, 50)[1:]
acf_abs = autocorrelation(np.abs(r), 50)[1:]
band = 2 / np.sqrt(r.size)

fig, ax = plt.subplots(figsize=(7, 3.5))
ax.plot(lags, acf_r, "o-", ms=3, label="$r_t$")
ax.plot(lags, acf_abs, "s-", ms=3, label="$|r_t|$")
ax.axhline(band, ls="--", c="k", lw=0.8)
ax.axhline(-band, ls="--", c="k", lw=0.8)
ax.set_xlabel("lag (days)")
ax.set_ylabel("autocorrelation")
ax.legend()
plt.tight_layout()
plt.show()
print(f"lag 1: r {acf_r[0]:.3f}, |r| {acf_abs[0]:.3f}, band {band:.3f}")
lag 1: r -0.024, |r| 0.166, band 0.028

Interpretation

Compare with your predictions. For market data (cont2001empirical?) reports insignificant linear autocorrelation of daily returns and a positive, slowly decaying autocorrelation of absolute returns. If your plot shows the same pattern, the returns are close to uncorrelated but they are not independent. The strong form of the random walk hypothesis, i.i.d. returns, fails.

Limitations

  • The \(\pm 2/\sqrt{n}\) band assumes i.i.d. data. With volatility clustering the true spread of the sample autocorrelation of \(r_t\) is wider, so a few crossings are not strong evidence (cont2001empirical?).
  • Closing prices that are not adjusted for dividends and splits create artificial jumps. Check the source of the frozen file.
  • Weekends and holidays are skipped, so a “daily” return sometimes covers three or more calendar days.

Optional extension

Exercise

Compute a 60-day rolling standard deviation of \(r_t\) with pandas.Series(r).rolling(60).std() and plot it. Mark the periods with the highest volatility. Do large returns cluster in those periods?

Solution

Shade the days where the rolling volatility is in its top 10 % and overlay the largest 1 % of absolute returns. If most of the large returns fall inside the shaded periods, they cluster.

import pandas as pd

vol = pd.Series(r).rolling(60).std().to_numpy()
high = vol > np.nanquantile(vol, 0.9)
big = np.abs(r) > np.quantile(np.abs(r), 0.99)

fig, ax = plt.subplots(figsize=(8, 3))
ax.plot(dates[1:], vol, lw=0.8)
ax.fill_between(dates[1:], 0, np.nanmax(vol), where=high, color="grey", alpha=0.3)
ax.plot(dates[1:][big], vol[big], "r.", ms=4)
ax.set_ylabel("60-day rolling std")
plt.tight_layout()
plt.show()
print(f"share of the largest returns in high-volatility periods: {np.mean(high[big]):.2f} (about 0.10 without clustering)")

## Solution

Lag 0 needs care, because `x[:-0]` is empty. Slice with `x[: x.size - k]` instead.

```python
def autocorrelation(x, max_lag):
    """Sample autocorrelation at lags 0..max_lag."""
    x = x - x.mean()
    return np.array([np.sum(x[: x.size - k] * x[k:]) / np.sum(x * x) for k in range(max_lag + 1)])
```
